# Тестик

React + TypeScript + Vite + Telegram UI.

## Запуск

Из папки testik:

```sh
npm install
npm run dev
```

Открой адрес из терминала. Стартовая кнопка проверяет работу React и Telegram UI. Под ней в браузере есть переключатель светлой и тёмной темы. Начальная тема соответствует системной.

```sh
npm run build
npm run preview
```

Node.js 20.18.1 поддерживается. React 18 выбран под peerDependencies Telegram UI. Vite 6 выбран для установленной версии Node.js.

## Готовые шаги

1. Основа проекта и один стартовый экран.
2. Официальный Telegram WebApp API: ready/expand, тема Telegram и обработка themeChanged, платформа iOS/base, стабильная высота и безопасные отступы экрана.

В Telegram браузерный переключатель скрыт, оформление задаёт клиент. Для проверки внутри Telegram потребуется бот разработки и HTTPS-адрес, настроенный в BotFather. Это отдельный следующий шаг; localhost используется для браузера.

Наличие initData используется для определения среды. Это не авторизация. Проверку подписи на сервере, тесты, навигацию и сохранение ответов добавим отдельными шагами.

Документация: https://core.telegram.org/bots/webapps#initializing-mini-apps
